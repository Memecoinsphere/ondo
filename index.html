          Paramètres

          Facultatif : sans clé, Ondo utilise des instances publiques Piped pour la recherche. Avec une clé, la recherche passe par l'API officielle de YouTube (plus fiable). Pour obtenir une clé gratuite : ouvrez la Google Cloud Console (console.cloud.google.com), créez un projet, activez YouTube Data API v3 dans « API et services », puis créez une clé API dans « Identifiants ». La clé reste stockée uniquement dans ce navigateur (localStorage).

          La lecture utilise toujours le lecteur officiel YouTube intégré.
